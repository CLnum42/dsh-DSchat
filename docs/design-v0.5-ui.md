## 1. 新提问自动置顶

**现在**：发送后视口钉在底部（`pinnedRef` → `scrollTop = scrollHeight`），回答每长一行就把内容推走一次，读者要一直滚才能从头读。

**改后**：发送成功那一刻，把这条提问的顶部对齐到消息区顶部 + 12px；此后流式增长**不再自动滚动**，回答在它下面长出来。

| 时机 | 视口行为 |
|---|---|
| 发送新消息 | 该条提问顶部对齐消息区顶部 +12px（新） |
| 回答流式增长 | 保持锚点，不动（新） |
| 打开面板 / 切换会话 | 钉在底部（最新），不变 |
| 自己滚到底部 | 重新进入「跟随最新」 |
| 搜索跳转 | 命中行居中 + 高亮，不变 |
| 不在底部时 | 右下浮出 `↓ 最新` 小胶囊，点了回到底部并重新跟随 |

## 2. 右侧提问导航

照 chat.deepseek.com 的交互做的（官网实测：`position:fixed`、34px 宽、刻度 8×2px/圆角 4px/`rgba(0,0,0,.16)`、当前条目 12px 宽 + `rgb(57,100,254)`、行距 30px、悬停展开成清单）。

- **收起态**：右缘一枚 34px 宽悬浮胶囊，每条提问一道刻度，间距 10px；当前条目 12×3px + 面板强调蓝。
- **悬停**：胶囊向左展开成 **268px** 提问清单（序号 + 单行省略的提问原文，行高 30px），指针所在行加深。
- **点击**：平滑滚到该提问、居中、落点高亮 1.8s（复用搜索跳转那套高亮）。
- **不挡正文**：导航出现时消息列右侧预留 58px 内边距。
- **出现条件**：提问 ≥ 2 条 **且** 消息区确实可滚动，否则整条隐藏。
- **无障碍**：一列 `<nav>` + 按钮，`Tab` 进入 / `↑↓` 移动 / `Enter` 跳转 / `Esc` 收起。

## 4. 输入区 UI 统一

功能不动，只把三套并存的尺寸/形状收敛成一套：**控件高度统一 30px**、**圆角回到面板自己的刻度（卡片 24 → 20px）**、**「文字+图标」一律胶囊 /「纯图标」一律圆形**；动作行去掉与卡片描边重复的那条细线。

备选方案：一体化 Dock（动作行搬进卡片顶部，整个输入区只剩一个带边框的盒子）。

## 5. 入口改名 + 从网页「同步」改为增量

两项跟进，都不改布局：

**入口名**：侧边栏那一行从 `DSchat` 改成 **`Chat`**（`nav.label`，`panel.title` 同步）。
插件自身的名字仍是 dsh-DSchat（设置 → 插件、包名、README 标题都不动）—— 改的只是它在侧边栏
里的那个入口，因为「Chat」是这个面板的功能，不是插件的型号。

**同步 = 合并，不是替换**（`TranscriptStore.mergeHistory`）：

| 情况 | 旧行为 | 新行为 |
|---|---|---|
| 本地没有的会话 | 收进来 | 不变 |
| 两边都有的消息 | **整体替换**：id、时间、思考用时全部换成新生成的 | 保留本地的 id / 时间 / `thinkingMs` / 附件，只取其文本 |
| 本地被截断的回复 | 整体替换 | **就地补全**（同一条消息，id 不变） |
| 本地多出来的消息（网页端没有） | **被丢掉** | 保留，位置不变 |
| 网页端重新生成过某条回答 | 整体替换 | 原地换成网页的文本，id 仍是本地的，不会出现两条 |
| 两边内容完全对不上 | 谁长用谁 | 不变（无对应关系时不按位置硬凑） |

对齐按**内容**而不是位置：比较用的是 `contentKey`（去掉思考块、引用标记、空白差异），
所以「只抓到最后一轮的旧记录」这种历史遗留也能对上，而不是把整段网页记录追加在后面。

同步结束后会报一句「新增 N 条 · 补全 N 条 · 更新 N 条 · 本地保留 N 条」（只显示非零项），
面板与 `dschat_recover` 都会报。侧边栏每一行悬停时多了一个「从网页同步这条」按钮 ——
左下角那个按钮只收本地没有的会话，要补全已有的某一条就用它。

## 实现要点（来自真实渲染的实测值）

| 探针 | 实测 |
|---|---|
| 导航收起 | 34 × 150px，刻度 8×2px / `rgba(0,0,0,.12)`，行距 **30px** |
| 导航展开 | **268px**，行高仍是 30px（`rowStable: true` —— 展开时行不位移） |
| 正文留白 | 消息列 `padding-right: 58px` |
| 发送后锚定 | 该提问距消息区顶部 **12px** |
| 点击跳转 | 同上 12px；当前刻度同步跟随；`↓ 最新` 出现 |
| `↓ 最新` | 点击后自身消失，距底部 **0px** |

回归测试 `test/scroll-anchor.test.ts`（真实 Chromium）把上面每一条都断言住，包括
「展开时第一行不位移」这一条 —— 它曾经是**真的会位移**，指针在展开瞬间离开按钮，
点击落空，测试先抓到、随后改成与官网一致的行距固定方案。
