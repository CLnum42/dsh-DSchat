# dsh-DSchat · UI 原型

这是一个**静态原型**，用来在你点头之前先把 dsh-DSchat 的界面定下来。它不是插件本身，
但尽力做到"所见即所得"：

- **侧边栏**用 DSH 自己的样式表渲染（`refs/sidebar.css`，原样提取自 `client-ui-sidebar/SidebarRoot.module.css`），
  包括左栏那个 `DSchat` 面板入口——真机上它就是通过 `sidebar.panellist` 注册出来的原生导航行。
- **颜色**全部走 DSH 自己的 token（`refs/dsh-tokens.css`，提取自 `client-ui-theme`），
  所以浅色/深色切换就是真机上 `body[data-ds-dark-theme]` 的效果，不是我自己配的色。
- **面板本体**（header / 会话栏 / 消息流 / 输入区 / 迁移面板 / toast）是 dsh-DSchat 的设计。

## 打开

```bash
open "prototype/dsh-DSchat-prototype.html"
```

顶部有一条**原型控制栏**（真机上不存在），可以切换：

| 控件 | 用途 |
|---|---|
| 主题 浅色/深色 | 检查两种配色下的对比度 |
| 状态 已登录/思考中/未登录/引擎错误 | 检查状态胶囊与底部状态行的四种表达 |
| 场景 空会话/带附件/消息出错/显示消息操作 | 检查空状态、附件 chips、错误重试、消息 hover 操作条 |

可以交互的部分：搜索会话、新建/删除会话（删除后有 6 秒撤销）、发送消息（会模拟流式回复并计时计字数）、
「在 Harness 中继续」下拉面板（切换迁移方式与目标、点开始迁移会跑阶段进度）、代码块复制、头部会话栏折叠、
窄窗口下会话栏变成抽屉。

## 对照当前 dsh-webchat 的改动

| 现在的做法 | 原型里的做法 |
|---|---|
| `MutationObserver` 往中心栏塞 DOM，再用 CSS 把原生会话区 `display:none` | 注册 `main` 槽位，是真正的原生面板，不碰 DOM、不遮挡任何东西 |
| 侧边栏入口是注进去的一行按钮 | `sidebar.panellist` 原生导航行，和「插件」「任务」同一视觉层级 |
| 底部一长排 `select` + 按钮做迁移 | 头部主按钮 + 下拉面板，三段式进度，完成后自动跳会话 |
| 状态只有一个点和一行字 | 状态胶囊（阶段 + 可做动作）+ 底部状态行（本轮输出字数/耗时） |
| 图片附件要手填路径 | 输入框上方附件 chips，支持拖拽/粘贴 |
| 删除要二次确认，toast 一闪而过 | 删除即生效 + 6 秒撤销；toast 带可直接点的动作 |
| 消息是左右两个大泡泡 | 你 → 右侧气泡；助手 → 左侧整宽块排版，代码块/表格/引用/列表按原生 markdown 规范渲染 |

## 渲染截图（可选）

`shot.mjs` 用本包依赖的 playwright-core + 本机 Chrome 无头渲染全部场景，
产物写进 `prototype/.tmp-shot/`（scratch 目录，不入库）：

```bash
node shot.mjs "$(pwd)/dsh-DSchat-prototype.html"
```

`screenshots/` 里那 9 张就是这套渲染的成品（改名 + 转 1600px WebP 后提交）。
脚本跑完会打印页面控制台错误数；`errors: none` 表示原型在真实浏览器里没有报错。
